## Status meanings

- **IMPLEMENTED**: the configuration, code, or documentation exists; successful execution is not implied.
- **VERIFIED**: the requested behavior was observed in a real execution, with the date/output recorded where available.
- **IMPLEMENTED AND VERIFIED**: both the artifact and its execution are evidenced.
- **IMPLEMENTED BUT NOT TESTED**: an implementation artifact exists, but it has not been built, executed, or deployed in the target runtime.
- **NOT IMPLEMENTED**: no actual implementation/action was completed for the requirement.
- **BLOCKED**: a missing runtime, requirement detail, authentication, or other prerequisite currently prevents completion.
- **VERIFIED WITH EXCEPTION**: execution is verified with an explicitly documented exception; it does not claim strict compliance with a literal interpretation.
- **USER-MANAGED**: intentionally deferred to the user by explicit instruction.
- Older status labels below are retained only for the completed Linux history; remaining sections use the four statuses above.
